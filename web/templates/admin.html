Quỹ Google Gemini API Key Dùng Chung

Nhập các API Key của trung tâm vào đây (mỗi dòng một key). Hệ thống sẽ tự động xoay tua đa luồng (Multi-Key Affinity) khi nhiều giáo viên cùng chuyển đổi, chống lỗi chạm hạn mức (Rate Limit 429).

💡

Lưu ý để API Key vĩnh viễn không bao giờ mất trên Cloud / Render:

Nếu bạn đang chạy trên Render (Gói Free), máy chủ sẽ tự động ngủ (spin down) khi không có người dùng sau 15 phút và reset ổ đĩa tạm. Để lưu API Key vĩnh viễn 100%, bạn chỉ cần vào Dashboard Render → mục Environment → thêm biến GEMINI_API_KEYS (dán các API Key vào đó). Khi đó, mỗi lần máy chủ khởi động lại sẽ tự động nhận diện ngay lập tức!
